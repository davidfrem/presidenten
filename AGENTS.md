# Projectinstructies

- Lees `DEPLOY_CLOUD_RUN.md` voordat je Google Cloud controleert of naar Cloud Run deployt.
- Cloud Run wordt vanuit deze Mac beheerd met de Google Cloud CLI. Neem niet aan dat `gcloud`
  in `PATH` staat; gebruik de sectie "Deployen vanaf deze Mac" uit de handleiding.
- De publieke singleplayer-versie op GitHub Pages mag alleen worden gewijzigd wanneer de
  gebruiker dat expliciet vraagt.
